# Índice de referências

Leia apenas este `INDEX.md` para a curadoria inicial. Depois de selecionar os IDs, abra somente os arquivos de categoria pertinentes.

- **[Mídia]** — Tipográfico dispensa fotografia. Foto-Adaptável aceita mídia equivalente. Foto-Crítica depende do tipo de fotografia especificado.
- **[Scroll]** — Estático segue o fluxo normal. Sticky inclui conteúdo fixado durante parte da rolagem.
- **[Fundo]** — Escuro, Claro ou Adaptável indicam o tratamento de superfície do padrão.

As larguras e condições efetivamente medidas constam dos lotes em `raw-audits/`.
